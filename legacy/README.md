# AeroSwarm Legacy Code

This directory contains earlier AeroSwarm implementations retained for
historical and algorithmic reference.

The files in this directory are not part of the active AeroSwarm build.

Some legacy implementations contain exploration ideas that may still be
useful when developing future search policies, but new development should
target the current architecture under:

- `include/aeroswarm/`
- `src/`
- `tests/`

Do not introduce dependencies from the active implementation back into
`legacy/`.
